# Attribution and originality

The component and block source in this repository is original Beautiful CSS work. No third-party
component implementation or visual asset is included in the registry output.

The geometric `public/media-poster.svg` artwork was created for this repository and is used only as
demonstration media. Consumers supply their own media when using the Editorial Project Hero block.

Development and runtime packages listed in `package.json` are not redistributed as part of an
installed registry item and remain subject to their respective licenses. Instrument Sans is loaded
through `next/font` for the catalogue website; installed components and blocks inherit the
consumer's typeface.

If a future item adapts third-party code or bundles a third-party asset, its source and license must
be recorded here before that item can enter the public registry.
